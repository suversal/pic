# MagicPin

写 X 文章用的配图工具：拼图、美化、标注、隐私遮挡，一站完成。纯前端，图片只在本机浏览器处理，不上传。

## 运行

```sh
python3 serve.py
```

然后打开 http://127.0.0.1:8765/ 。`serve.py` 和 `python3 -m http.server` 一样，只是禁止浏览器缓存，改完代码刷新即生效。“复制图片”需要 localhost 或 https 环境。没有图片时可以点“用示例图试试”。

## 功能

**图片与布局**（左栏）

- 导入：按钮、拖入窗口或 ⌘V 粘贴，支持 iPhone 的 HEIC 照片（Chrome 等不支持 HEIC 的浏览器会在本机自动转成 JPEG，解码器 `js/vendor/heic-to.js` 首次用到时才加载）；拖动列表排序；单张图裁剪、旋转、翻转。
- 布局：纵向、横向、网格（2～4 列），间距。间距为 0 且几张图正好拼成一个完整矩形时当成一整张：外框、圆角、阴影只在整体外面套一次（长截图拼接后就是一台完整的手机 / 一个窗口），间距大于 0 时每张各自套。“统一宽度 / 高度”默认关：每张图保持原始像素尺寸（或手动缩放后的大小），裁剪哪张只有哪张变小；打开后按最窄（矮）或最宽（高）把所有图缩放到一样宽（高），切回“关”时回到原始尺寸。长截图拼接会自动打开。
- 位置：图片按顺序紧挨着排，另一个方向默认靠上 / 靠左，不会自动居中；选择工具下按住图片可以拖到任意位置（吸附其他图片的边缘和中线，按住 ⌥ 不吸附）。“对齐”选顶部 / 居中 / 底部（纵向是靠左 / 居中 / 靠右）会把所有图重新排齐，手动拖过的位置还原。
- 缩放：选择工具下点一张图，四角出现控制点，拖角等比放大或缩小，只有这张图在变：对角固定，其他图不会被挤开；外框、圆角、阴影跟着这张图一起缩放，其他图的外框、背景图案和水印不受影响；放大后可以叠在别的图上，点“对齐”重新排齐（吸附原始大小和其他图片的宽高，按住 ⌥ 不吸附），旁边显示当前比例，超过 100% 时提示可能变糊；双击控制点恢复原始大小。统一宽度开着时拖角会自动关掉它，从当前大小开始调。
- 画布：裁剪、拖动、缩放图片时画布和没动的图片留在原地，画布只在内容超出时变大，不会跟着缩。松手（裁剪是点完成）后，画面保持不动，自适应画布收紧到内容加留白（画布跑出窗口可见范围时才平滑回到中间）；固定比例画布保持当前尺寸，不再自动缩小，需要时点“画布尺寸”旁的“贴合内容”收紧。
- 长截图拼接：自动识别相邻截图的重叠内容，裁掉重复部分和中间的固定栏；识别不可靠时宁可不拼。
- 裁剪：底部工具栏的裁剪工具（C），点一张图开始（只有一张图时直接进入），也可以在选择工具下双击图片。拖四条边或四个角裁剪（拖角同时裁两条边），拖图片本身移动截取窗口（长截图上下滑动对齐接缝），方向键微调（⇧ 每次 10px）。常用比例一键套用：自由、原图、1:1、4:3、3:4、16:9、9:16、5:2（X 文章头图）；选了比例后拖边会锁定比例。点另一张图切换，Esc / Enter 或点空白处完成。
- 取消拼接：拼接后按钮变成“取消拼接”，一键还原参与拼接的图片裁切和拼接前的布局（排列方式、间距、统一宽度）。
- 还原裁切：一键把所有图片恢复原始尺寸（裁切和缩放都还原）；拼接过的话，布局也回到拼接前。

**外观**（右栏）

- 折叠：模板、图片外框、背景画布、水印每块都能点标题折叠，展开状态记在本机，下次打开沿用；打开背景或水印开关时对应的那块自动展开。
- 模板：11 个内置模板，覆盖每种外框，背景混用弥散、渐变、纯色加圆点或网格、模糊原图；留白和颗粒统一，配色是同一组低饱和色，深色款带中心微光和暗角，缩略图直接用你的图片实时预览；再点一次已选中的模板（或点“无”）即可取消，外观还原到套用前；随机换一个（S）；可把当前外观存为自己的模板（右键删除）。
- 图片外框：玻璃、白边、黑边、iPhone、Mac 窗口（浅 / 深，可写标题）、浏览器窗口（浅 / 深，可写网址）；玻璃、白边、黑边可调边框粗细；圆角内外同心，调到 0 就是直角；多层柔和阴影也在这里调（阴影投在背景画布上，背景关闭时不显示）。
- 背景画布（有开关）：关闭时只导出图片和外框，四周透明；打开后可选弥散渐变、线性渐变、纯色、自定义图片、模糊原图，叠加颗粒质感和图案（14 种：圆点、方格、斜线、十字、横线、波浪、折线、棋盘、格纹、蜂窝、三角、同心圆、放射、散点，缩略图按当前背景色实时预览，可调深浅），并设置画布比例（含 5:2 X 文章头图）和留白。再次打开会恢复上次的背景。
- 水印：四角、居中或平铺（可调密度和角度）；颜色可设为“自动”，按背景明暗选黑白。

**标注与遮挡**（底部工具栏）

- 文字（5 种字体：默认、圆体、宋体、楷体、等宽；左 / 中 / 右对齐；纯文字 / 描边 / 阴影 / 标签）、箭头、矩形、椭圆、直线、画笔、序号、高亮、聚光灯、放大镜、表情贴纸。
- 字号、线条粗细、贴纸和放大镜大小直接输入像素值（按 1× 导出尺寸计），也可以按住数值左边的名称左右拖动（按住 ⇧ 每次 10px）；贴纸、放大镜、序号、文字选中后拖四角等比缩放。
- 选择：选择工具下在图片外的空白处拖动框选（按住 ⇧ 在图片上也能框选），⇧ 点击加选减选，⌘A 全选；多选后可一起拖动、改颜色、复制、置顶、删除。按住空格或鼠标中键拖动平移画面。
- 对齐：拖动标注时自动吸附到画布中线、图片边缘与中线、其他标注的边缘与中线，并显示参考线；按住 ⌥ 临时关闭。画新的框（遮挡、矩形、高亮、箭头等）、拖控制点调大小时，鼠标所在的点也会吸附并显示参考线：还没按下时靠近能对齐的位置就会出现，拖动中起点和终点的对齐线都会保留。
- 用画图工具时只会抓起同类对象，其余对象上照常画；要移动任意对象用选择工具（V）。
- 遮挡：纯色（敏感信息用这个）、马赛克、模糊；马赛克和模糊强度不低于 12px。拖出、移动、调整遮挡（以及高亮、聚光）时会描出框的四条边，看得清范围；松手后不显示，也不进导出图。
- 遮挡和标注跟随所在图片，改布局、顺序、裁剪时不会错位；跨图遮挡按图片自动拆分；放大镜不会放大遮挡下的内容；已有遮挡的图片不允许旋转翻转。

**导出**（右上角）

- 整张拼图或逐张导出：逐张时每张图单独一个文件，带同样的外框、背景和水印，适合发 X 多图帖。
- PNG / JPEG / WebP，0.5× / 1× / 2×。
- “适配 X”：超过 5 MB 时自动降低质量或缩小尺寸。
- 导出时重新绘制，只含最终像素，不带编辑框和原图数据。

底部工具栏最右边是撤销、重做和还原。还原会去掉所有改动，回到导入时的样子：图片按导入顺序排列并恢复原始尺寸，标注、遮挡和拼接全部去掉，布局、外观和水印回到第一次导入时的设置。

移除图片、清空、删除多个对象、还原裁切、取消模板、长截图拼接、还原之后，提示里都有“撤销”按钮。

外观、工具默认值、导出设置和主题会记在本机浏览器里，下次打开沿用。当前作品（图片原文件和所有编辑）自动保存在本机浏览器的 IndexedDB 里，刷新或误关后重新打开即恢复；点“清空”后不再保留。这些数据都不离开你的电脑。

## 快捷键

按 `?` 查看全部。常用：

| 键 | 作用 |
| --- | --- |
| V C M T A R O L P N H F Z E | 选择、裁剪、遮挡、文字、箭头、矩形、椭圆、直线、画笔、序号、高亮、聚光、放大镜、贴纸 |
| S | 随机模板 |
| ⌘Z / ⇧⌘Z | 撤销 / 重做 |
| ⇧⌘C / ⌘S | 复制图片 / 下载 |
| ⌘D、] / [ | 复制对象、置顶 / 置底 |
| ⌘= / ⌘- / ⌘0 / ⌘1 | 放大 / 缩小 / 适应窗口 / 100%（顶栏中间也有缩放滑块和档位菜单，触控板可双指捏合） |
| 按住 ⇧ 拖动 | 直线和箭头吸附 45°，框保持正方形 |
| ⌘A、⇧ 点击 | 全选、加选 / 减选 |
| 按住空格拖动 | 平移画面 |
| 按住 ⌥ 拖动 | 不吸附对齐 |
